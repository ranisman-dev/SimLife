Behavior:

  - `const Sim = require('../sim.js');` and `const BASELINE = path.join(__dirname,
    'baseline.json');` — resolve the baseline relative to `__dirname`, not the process
    CWD, so the script works when invoked from anywhere.
  - Parse flags with plain `process.argv.includes('--update-baseline')`. No argv-parsing
    library: this is a zero-dependency project with no `package.json`, and adding one
    would be disproportionate.
  - Load the baseline if `scripts/baseline.json` exists; otherwise treat it as absent.
  - Call `Sim.runRegressionCheck(baseline ? { baseline } : {})`.
  - Print, in this order:
      1. a header line naming the seed the run used (`Sim.DEFAULT_SEED`), so the output
         states its own reproducibility conditions;
      2. one line per entry in `result.checks`, formatted `PASS <name> :: <detail>` or
         `FAIL <name> :: <detail>`;
      3. when `result.diffs` is present and non-empty, a `Baseline diff:` header followed
         by `Sim.formatDiff(result.diffs)` — the field-by-field, old-to-new rendering
         D-09.3 requires. Never dump raw JSON.
      4. a final `OVERALL: PASS` / `OVERALL: FAIL` line.
  - Exit codes: `process.exit(0)` when the run passed, `process.exit(1)` otherwise.

Missing-baseline behavior (plain run, no flag): print the qualitative check lines
normally, then an explicit line stating that `scripts/baseline.json` was not found and
that `node scripts/verify.js --update-baseline` captures the first one, and exit **1**. A
missing baseline is not a pass — the golden-master half of the check did not run.

`--update-baseline` behavior (D-09.2, the golden-master re-baseline workflow — this
exists so a human reviews a diff and confirms an intentional change instead of
hand-editing JSON):
  - Run the check exactly as above and print everything above, **including the full
    baseline diff**, before writing anything. The human must see what they are about to
    bless.
  - Then write `JSON.stringify(result.snapshots, null, 2)` plus a trailing newline to
    `scripts/baseline.json`, and print a confirmation line naming the path and how many
    diff entries were just accepted.
  - Exit 0.
  - The write happens **only** under the explicit flag. A plain failing run must never
    silently rewrite the baseline.

All formatting and printing lives in this file. Do not add `console.log` to `sim.js`, and
do not reimplement diffing or snapshotting here — call `Sim.formatDiff` and
`Sim.runRegressionCheck`.
