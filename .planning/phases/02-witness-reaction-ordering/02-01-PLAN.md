<objective>
Capture the ORDER-02 "before" side: make dispatch order observable as event data, build the
scripted five-witness scenario the whole phase is judged on, and freeze the current
`forEach`-order reaction cascade into a committed fixture — all before any behavior changes.

Purpose: ORDER-02 requires the fix's effect to be *confirmed, not assumed*. That is only
possible if the pre-fix order is captured from pre-fix code. This plan is deliberately the
only plan in the phase that runs against unmodified dispatch logic.

Output: `event.witnessOrder` provenance on every event, `ORDER_SPEC` /
`buildOrderingScenario()` / `orderingSnapshot()` / `runOrderingCheck()` in `sim.js`, the
frozen `scripts/order-prefix.json`, the live `scripts/order-baseline.json`, and a
`scripts/verify.js` that runs and prints both.
