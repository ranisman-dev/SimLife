regression harness, and verify that Phase 2's and Phase 3's guarantees survive the Tell/Move
appraisal changes.

ORDER-01 qualitative checks rather than merely producing a re-blessable diff. Unlike Phase 3's
equivalent task there is no tunable constant to fall back on here, so the branch is binary:
green → record and stop; any red → STOP and report.
